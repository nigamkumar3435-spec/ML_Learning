# Machine Learning Learning Journey 🚀

Welcome to the **ML_Learning** repository! This repository serves as a structured collection of code, notes, and projects tracking a complete journey into the world of Machine Learning using Python. 

Whether you are reviewing the foundations of Python or diving deep into complex algorithmic models, this repository is organized to provide a clear, step-by-step learning path.

## 📂 Repository Structure

The repository is modularly structured, progressing from foundational programming skills to advanced Machine Learning concepts:

### 1. Fundamentals & Data Handling
* **`PythonBasics/`**: Core Python programming concepts essential for data science and algorithm logic.
* **`NumpyBasics/`**: Numerical computing, array manipulation, and mathematical operations using NumPy.
* **`PandasSeries/`**: Data manipulation, cleaning, and exploratory data analysis (EDA) using Pandas.
* **`DataReading/`**: Methods and scripts for importing, parsing, and handling various data formats (CSV, JSON, Excel, etc.).

### 2. Data Visualization
* **`Graphs/`**: Visualizing data distributions, feature relationships, and model performances using visualization libraries.

### 3. Machine Learning Algorithms
* **`RegressionClassification/`**: Core predictive modeling techniques, focusing on continuous (regression) and categorical (classification) predictions.
* **`SupervisedLearning/`**: Implementations of supervised algorithms including Decision Trees, Support Vector Machines (SVM), Random Forests, and more.
* **`Unsupervised_MachineLearning/`**: Techniques for discovering hidden patterns in unlabeled data, including clustering (e.g., K-Means) and dimensionality reduction.

## 🛠️ Tech Stack & Libraries
This repository is 100% Python-based. The primary libraries explored across the modules include:
* **Python 3.x**
* **NumPy**
* **Pandas**
* **Matplotlib & Seaborn**
* **Scikit-Learn**
